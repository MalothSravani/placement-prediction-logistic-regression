# 🎓 Placement Prediction using Logistic Regression

## 📌 Project Overview

This project demonstrates a basic Machine Learning classification problem using **Logistic Regression**. The model predicts whether a student will be placed based on their **CGPA** and **IQ**.

The project covers the complete workflow, including data preprocessing, train-test splitting, feature scaling, model training, evaluation, and visualization of decision boundaries.

## 📊 Dataset

The dataset contains the following features:

| Feature | Description |
|---------|-------------|
| CGPA | Student's CGPA |
| IQ | Student's IQ Score |
| Placement | Target Variable (0 = Not Placed, 1 = Placed) |
